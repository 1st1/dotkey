## Google Fonts catalogue — `packages/core/src/generated/googleFonts.json`

Generated by `tools/gen-fonts.mjs` from Google's public font metadata endpoint
(`https://fonts.google.com/metadata/fonts`, no API key required). It records only
factual availability data — family names and which weights and italics each
publishes — so that a stylesheet request never names a weight that does not
exist. No font data is included or redistributed.

The fonts themselves are served by Google Fonts at runtime under their own
licences (mostly SIL Open Font License), and only when the host opts in.
